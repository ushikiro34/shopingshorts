1. 검증 전 항목 통과 + interfaces.md와 구현 일치 + plan.md 산출물 요약 기록 완료 시 `완료`.

3. Phase 2의 "대본 품질"은 형식 검증 통과 후 사용자 직접 심사(샘플 5개 중 4개 승인)가 최종 게이트.
